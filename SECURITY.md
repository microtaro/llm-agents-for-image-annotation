# Security

The app is for one person on their own computer. It listens only on `127.0.0.1`, has no login, and its `/mcp` endpoint gives a connected client every tool with no approval step. Requests from pages on other sites are refused. Don't expose it to a network.

To report a security problem, use **Report a vulnerability** on the repository's [Security tab](https://github.com/microtaro/llm-agents-for-image-annotation/security). Please don't open a public issue for it.
